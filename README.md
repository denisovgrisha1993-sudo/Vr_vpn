# OneTap VR

OneTap VR is a modified, VR-optimized VPN client built upon the open-source [v2rayNG](https://github.com/2dust/v2rayNG) project.

## Features
- Optimized for standalone VR devices (Meta Quest) and Android.
- Clean and simple interface.
- Direct integration with private infrastructure.
